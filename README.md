# Flight Price Prediction ✈️

## Project Overview
Flight Price Prediction is a machine learning project that predicts flight ticket prices based on available flight data. The project uses Python and machine learning techniques to analyze flight-related features and estimate ticket prices.

## Dataset
- **File:** `Data_Train.xlsx`
- **Format:** Excel
- Contains the training data used for building the prediction model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model
- Random Forest Regressor

## Evaluation Metrics
The model's performance is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Files
- `Flight_Price_Prediction.ipynb` — Jupyter notebook containing the project code.
- `Data_Train.xlsx` — Dataset used for training.

## How to Run
1. Download or clone this repository.
2. Open `Flight_Price_Prediction.ipynb` in Google Colab or Jupyter Notebook.
3. Upload `Data_Train.xlsx` to the environment.
4. Update the dataset path in the notebook if necessary.
5. Run the notebook cells in order to train and evaluate the model.
